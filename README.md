# 証券コード・銘柄名 変換辞書

上場企業の証券コードと銘柄名を、日本語入力で相互に変換できるようにする辞書ファイルです。
証券コードを入力して銘柄名に変換したり、銘柄名の読みを入力して証券コードに変換したりできます（1銘柄につき最大8通りの変換）。
**Microsoft IME と Google日本語入力 のどちらでも使えます。**

例: `9432` → `ＮＴＴ(9432)` / `えぬてぃてぃ` → `9432`

## ダウンロード

最新の版はこちらからダウンロードしてください（GitHub のアカウントは不要です）。

**https://github.com/sokosoko-stockcode-jp/stockcode-ime-jp/releases/latest**

このリンクは固定リンクで、毎月の更新後も常に最新の版を指します。リンク先の **Assets** から `stockcode_ime_2026_oct.zip` のような ZIP ファイルをダウンロードしてください。
ZIP には、Microsoft IME用（UTF-16）と Google日本語入力用（UTF-8）の2つのテキストファイルが入っています。中身は同一です。
ファイルの配布はすべてこの Releases 経由で行います（他の場所にある同じ名前のファイルは公式の配布ではありません）。

## 取り込み手順（Microsoft IME）

1. ZIP ファイルを解凍し、中の `stockcode2026_oct_ime.txt`（UTF-16版）を取り出します
2. 「Microsoft IME 辞書ツール」を開きます（スタートメニューで「辞書ツール」と検索）
3. メニューの「ツール」→「テキストファイルからの登録」を選びます
4. 解凍した `stockcode2026_oct_ime.txt` を選択して登録します
5. メモ帳などで `9432` と入力して変換し、`ＮＴＴ(9432)` に変換できるか確認してください

## 取り込み手順（Google日本語入力）

1. ZIP ファイルを解凍し、中の `stockcode2026_oct_utf8.txt`（UTF-8版）を取り出します
2. Google日本語入力の「辞書ツール」を開きます
3. 「管理」→「新規辞書にインポート」を選びます（既存の辞書に追加する場合は、先にその辞書を選んで「選択した辞書にインポート」）
4. 解凍した `stockcode2026_oct_utf8.txt` を選択して取り込みます
5. メモ帳などで `9432` と入力して変換し、`ＮＴＴ(9432)` に変換できるか確認してください

登録・取り込みはお使いの入力システムのユーザー辞書に追加されます。元の辞書を上書きするものではありません。
詳しい手順と今回の変更ログは ZIP 内の README と変更ログに同梱しています。

## 中身の確認

リポジトリ内の `stockcode2026_oct_updated.txt`（UTF-8）は閲覧・確認用です。ブラウザ上でそのまま読めます。
取り込みには、Releases の ZIP 内のファイルを使ってください（Microsoft IME は `_ime.txt`、Google日本語入力 は `_utf8.txt`）。

## 注意

- 銘柄名は JPX の表記を基準にしていますが、東京ガス・大阪ガス・東邦ガス・北海道ガス・ミズノの5銘柄は従来表記を維持しています
- 5桁コードの優先株式・社債型種類株式（7件）は対象外です
- 本辞書は入力支援を目的としたもので、投資助言ではありません
